# Food Lover 🍽️

A responsive, single-page website for **Food Lover**, a fine dining restaurant in Bosra Al-Sham, Daraa.

**Live site:** https://momar5413.github.io/food-lovers/

## Features

- Dark and gold design with elegant serif typography
- Sticky navigation that highlights the current section, with a slide-out menu on mobile
- Special offers, a full menu with prices, meal times, a photo gallery and a contact form
- Scroll-in animations (turned off automatically for users who prefer reduced motion)
- Works on phones, tablets and desktops

## Project structure

```
index.html        page markup
style/style.css   all styles
js/main.js        navigation, animations and contact form
img/              photos and logo
```

## Run locally

No build step is needed. Open `index.html` in a browser.

## Publish with GitHub Pages

In the repository go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
